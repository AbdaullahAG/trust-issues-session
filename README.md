# Trust Issues: Session Feedback

Your first Pull Request, for real. After the session **Trust Issues: Git, Code & Trust** (OWASP Amman), add one short Markdown file to the `entries/` folder:

- what you learned,
- one useful tip,
- or what you wish the session had covered.

It is a normal open source contribution: you fork, change, and open a Pull Request, and a maintainer reviews it before merging.

## How to join

Read [CONTRIBUTING.md](CONTRIBUTING.md). There are two paths: **in your browser** (no Git needed) or **with Git commands**.

## The rules (the checks enforce them)

- Add **exactly one new file**: `entries/your-short-name.md` (lowercase letters, digits and hyphens).
- Use the three headings from [`entries/_TEMPLATE.md`](entries/_TEMPLATE.md).
- Keep it under 4 KB. **No links, no HTML, no secrets, no personal data.**
- Write it yourself. If an AI helped, say so in the Pull Request.

## Good to know

- Your contribution appears under your GitHub account, like any other contribution.
- What gets merged stays in the repository history, so don't put anything in it you wouldn't want public.
- Every commit shows its author email. Turn on **Keep my email addresses private** in your GitHub email settings and use your `noreply` address before your first push.
- Entries are public. The maintainer may quote them, without your name, to improve this session or future talks.

## بالعربي باختصار

أضف ملفًا واحدًا قصيرًا في مجلد `entries/` فيه ثلاثة عناوين: ما تعلّمته، ونصيحة مفيدة، وما كنت تتمنى أن تطرحه الجلسة. اقرأ `CONTRIBUTING.md` واختر المتصفح أو الأوامر. يمكنك الكتابة بالعربية أو الإنجليزية. بلا روابط ولا بيانات شخصية.
